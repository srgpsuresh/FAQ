1. Reverse a String

Interview Explanation

Definition

Reverse the characters of a string without changing the original meaning.

Problem

Input: CSharp
Output: prahSC

Approach

  • Convert string to character array.
  • Use two pointers.
  • Swap first and last characters.
  • Repeat until middle.

Code

public static string ReverseString(string input)
{
    char[] arr = input.ToCharArray();

    int left=0;
    int right=arr.Length-1;

    while(left<right)
    {
        char temp=arr[left];
        arr[left]=arr[right];
        arr[right]=temp;

        left++;
        right--;
    }

    return new string(arr);
}
Real Project Use
  • Encryption
  • Data Formatting
  • Text Processing
Time Complexity O(n)

2. Palindrome

Interview Explanation

Definition

A palindrome reads the same from left to right and right to left.

Problem

MADAM → True
HELLO → False

Approach

  • Compare first and last characters.
  • Move towards center.

Code

public static bool IsPalindrome(string input)
{
    int left=0;
    int right=input.Length-1;

    while(left<right)
    {
        if(input[left]!=input[right])
            return false;

        left++;
        right--;
    }

    return true;
}
Real Project Use
  • Password Validation
  • Pattern Recognition
  • Search Algorithms
Time Complexity O(n)

3. First Non-Repeating Character

Interview Explanation

Definition

Find the first character appearing only once.

Problem

Input: aabbcde
Output: c

Approach

  • Count frequency using Dictionary.
  • Return first character having count = 1.

Code

public static char FindFirstNonRepeating(string input)
{
    Dictionary<char,int> map=new();

    foreach(char c in input)
    {
        if(map.ContainsKey(c))
            map[c]++;
        else
            map[c]=1;
    }

    foreach(char c in input)
    {
        if(map[c]==1)
            return c;
    }

    return '_';
}
Real Project Use
  • Log Analysis
  • Fraud Detection
  • Unique Data Validation
Time Complexity O(n)

4. Two Sum Problem

Interview Explanation

Definition

Find two numbers whose sum equals the target.

Problem

Array: 2 7 11 15
Target: 9
Output: 2 + 7

Approach

  • Store visited numbers in Dictionary.
  • Search target-currentValue.

Code

public static int[] TwoSum(int[] nums,int target)
{
    Dictionary<int,int> map=new();

    for(int i=0;i<nums.Length;i++)
    {
        int diff=target-nums[i];

        if(map.ContainsKey(diff))
            return new[]{map[diff],i};

        map[nums[i]]=i;
    }

    return new[]{-1,-1};
}
Real Project Use
  • Payment Matching
  • Budget Allocation
  • Financial Systems
Time Complexity O(n)

5. Remove Duplicate Elements

Interview Explanation

Definition

Remove duplicate values from an array.

Approach

  • Store values in HashSet.
  • Convert back to array.

Code

public static int[] RemoveDuplicates(int[] nums)
{
    HashSet<int> set=new();

    foreach(int num in nums)
        set.Add(num);

    return set.ToArray();
}
Real Project Use
  • Customer Master Cleanup
  • ETL Processing
  • Duplicate API Requests
Time Complexity O(n)

1. Object Oriented Programming (OOP)

Encapsulation

Definition

Wrapping data and methods into one class while hiding internal details.

Example

public class Employee
{
    private decimal salary;

    public void SetSalary(decimal amount)
    {
        if(amount > 0)
            salary = amount;
    }

    public decimal GetSalary()
    {
        return salary;
    }
}

Real Project

  • Employee Salary
  • Bank Account
  • User Profile
Performance Impact Improves security and maintainability.
Inheritance

Definition

Acquire properties and methods from parent class.

public class Vehicle
{
    public void Start(){}
}

public class Car : Vehicle
{
}

Real Project

  • BaseEntity
  • Vehicle Management
  • Employee Hierarchy
Reusable code.
Polymorphism

Definition

One interface, multiple implementations.

public interface IPayment
{
    void Pay();
}

public class CardPayment : IPayment
{
    public void Pay(){}
}

Real Project

  • Payment Gateway
  • Notification Services
Easy to extend features.
Abstraction

Definition

Hide implementation and expose only required functionality.

public interface IOrderService
{
    void PlaceOrder();
}

Real Project

  • Repository Pattern
  • Service Layer

5. async / await

Definition

Asynchronous programming without blocking the current thread. 

public async Task<string> GetDataAsync()
{
    await Task.Delay(1000);
    return "Success";
}

Real Project

  • Database Calls
  • API Calls
  • Azure Blob Storage
Interview Tip Async does not create a new thread. It releases the current thread while waiting.

Generation Description

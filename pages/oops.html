1. What is OOP?

Definition

Object-Oriented Programming is a programming methodology that models software using objects containing data and behavior.

Real-Time Example

Instead of creating hundreds of independent functions, we create business objects like Order, Customer, Product, Invoice and Payment.

Clean Architecture Usage

Domain Layer contains all business entities. Order Customer Invoice Product

Microservice Usage

Every microservice owns its own business objects. Order Service → Order Payment Service → Payment Inventory Service → Product

Benefits
  • Reusable
  • Maintainable
  • Scalable
  • Easy Testing
  • Loose Coupling

4. What is Encapsulation?

Definition

Encapsulation hides internal data and exposes only controlled behavior.

Wrong Design 

order.TotalAmount = -500;
Correct Design 

Order

AddItem()

RemoveItem()

ApplyCoupon()

CalculateTotal()
Clean Architecture Usage

Only Domain Entity modifies business rules. No external layer updates TotalAmount directly.

Enterprise Benefit
  • Protects Business Rules
  • No Invalid State
  • Centralized Validation

5. What is Abstraction?

Definition

Expose only required functionality while hiding implementation.

Example 

IOrderRepository

↓

SqlOrderRepository
Microservice Usage

Application Layer never knows SQL Server implementation.

Benefits
  • Database Independent
  • Easy Mocking
  • Easy Unit Testing

7. What is Polymorphism?

Definition

Same method behaves differently for different objects.

Project Example 

CalculateShipping()

↓

Domestic Order

↓

₹100

------------------

CalculateShipping()

↓

International Order

↓

₹1000
Benefit

Business logic becomes extensible without modifying existing code.

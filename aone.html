1. OOPs — Core Interview Questions

What is OOP? OOP organizes software around objects containing data and behavior.
What are the 4 pillars? Encapsulation, Abstraction, Inheritance and Polymorphism.
What is Encapsulation? Bundling data and behavior together while controlling access to internal state.
What is Abstraction? Hiding implementation details and exposing only essential functionality.
What is Inheritance? A derived class reuses and extends functionality of a base class.
What is Polymorphism? The same interface or method call can behave differently for different objects.
Overloading vs Overriding? Overloading is compile-time polymorphism; overriding is runtime polymorphism.
Interface vs Abstract Class? An interface defines a contract, while an abstract class can provide both state and implementation.
Composition vs Inheritance? Inheritance represents "is-a"; composition represents "has-a".
What is SOLID? Five principles for building maintainable, flexible and loosely coupled software.

2. C# — Core Interview Questions

What is C#? A strongly typed, object-oriented language used mainly for .NET application development.
Value Type vs Reference Type? Value types contain the value; reference types contain a reference to an object.
Boxing vs Unboxing? Boxing converts a value type to object; unboxing extracts the value type from the object.
var vs dynamic? var is resolved at compile time; dynamic is resolved at runtime.
const vs readonly? const is compile-time constant; readonly can be assigned during declaration or constructor execution.
ref vs out? ref requires initialization before passing; out does not.
String vs StringBuilder? String is immutable; StringBuilder is mutable and better for repeated modifications.
What is async/await? It enables asynchronous programming without unnecessarily blocking the calling thread during I/O waits.
Task vs Thread? Thread represents execution; Task represents an asynchronous unit of work.
IEnumerable vs IQueryable? IEnumerable generally works in memory; IQueryable can translate queries to the underlying data source.
What is LINQ? LINQ provides a consistent way to query collections and other data sources.
What is a Delegate? A type-safe reference to a method with a compatible signature.
What is Dependency Injection? Dependencies are supplied from outside instead of being created directly by the class.
What is Garbage Collection? .NET automatically releases managed objects that are no longer reachable.
What is IDisposable? It provides a standard mechanism for explicitly releasing disposable resources.

3. ASP.NET MVC — Core Interview Questions

What is MVC? MVC separates an application into Model, View and Controller for better separation of concerns.
What is a Controller? It receives requests, coordinates application logic and returns a response.
What is an Action Method? A controller method that handles a particular request.
What is Routing? Routing maps an incoming URL to the appropriate controller and action.
What is Model Binding? It maps HTTP request data to action parameters or model objects.
ViewBag vs ViewData vs TempData? ViewBag and ViewData pass data during the request; TempData can survive a redirect.
What is a ViewModel? A UI-specific object containing only the data required by a particular View.
Why use ViewModel? It prevents exposing database entities directly and allows UI-specific validation and shaping.
What are MVC Filters? Filters provide reusable logic for authorization, action processing and exception handling.
Authentication vs Authorization? Authentication verifies identity; authorization determines access permissions.
What is Dependency Injection? Required services are supplied to controllers instead of controllers creating them.
MVC Request Flow? Browser → Routing → Controller → Action → Service → Model → View → HTML Response.

4. Web API / REST API — Core Interview Questions

What is REST API? An HTTP-based API style that exposes resources through URLs and standard HTTP methods.
GET? Retrieves resources and should not modify server state.
POST? Usually creates a new resource or triggers a server-side operation.
PUT? Completely replaces a resource and is generally idempotent.
PATCH? Partially updates an existing resource.
DELETE? Deletes a resource and is generally idempotent.
PUT vs PATCH? PUT means complete replacement; PATCH means partial modification.
What is Statelessness? Each request contains the information required to process it without relying on previous requests.
200 vs 201 vs 204? 200 = success, 201 = resource created, 204 = success with no response body.
400 vs 401 vs 403? 400 = bad request, 401 = unauthenticated, 403 = authenticated but not authorized.
What is JWT? A signed token commonly used to carry authentication claims between client and API.
What is Middleware? A component in the HTTP pipeline that can inspect, modify or short-circuit requests and responses.
What is DTO? A Data Transfer Object controls the data contract exchanged between client and API.
What is API Gateway? A single entry point that can handle routing, authentication, rate limiting and other cross-cutting concerns.
How do you handle exceptions? Use centralized exception-handling middleware with consistent error responses such as ProblemDetails.
How do you improve API performance? Use async I/O, caching, pagination, efficient database queries and proper indexing.

5. Angular — Core Interview Questions

What is Angular? A TypeScript-based framework for building single-page and enterprise web applications.
What is a Component? A component combines TypeScript logic, HTML template and styling to represent part of the UI.
What is a Standalone Component? A component that can directly declare its dependencies without requiring an NgModule.
What is Data Binding? It connects component data and behavior with the HTML template.
Types of Data Binding? Interpolation, property binding, event binding and two-way binding.
What is a Service? A reusable class containing shared business, data-access or application functionality.
What is Dependency Injection? Angular automatically provides required service instances to components and other classes.
What is Observable? An Observable represents a stream of asynchronous values that consumers can subscribe to.
What is RxJS? A reactive programming library providing Observables and operators used extensively in Angular.
What is HttpClient? Angular's service for making HTTP requests to backend APIs.
What is an HTTP Interceptor? It can inspect or modify HTTP requests and responses, commonly for JWT, logging and error handling.
What is Routing? Angular Router maps URLs to components and enables client-side navigation.
What is a Route Guard? It controls whether navigation is allowed, redirected or blocked.
What is Lazy Loading? It loads features only when required, reducing the initial application bundle.
Reactive vs Template-driven Forms? Reactive Forms are programmatically controlled in TypeScript; Template-driven Forms are primarily configured in HTML.
What is Change Detection? Angular checks component state and updates the DOM when required.
What is OnPush? OnPush reduces unnecessary change detection by checking components primarily when relevant inputs or reactive state changes.
What is Signal? A reactive primitive used to hold state and efficiently notify consumers when the state changes.
Parent → Child communication? Use Input to pass data from parent to child.
Child → Parent communication? Use Output/EventEmitter to send events from child to parent.

6. Full-Stack Architecture — Remember This Flow

Frontend Angular Component → Service → HttpClient → REST API
Backend API Gateway → Middleware → Authentication → Controller → Service → Repository → Database
Response Database → Repository → Service → DTO → Controller → JSON → Angular Service → Component → UI
Interview Architecture Statement Keep Controllers thin, put business logic in Services, abstract data access, use DTOs, dependency injection, centralized exception handling, logging, authentication and authorization.

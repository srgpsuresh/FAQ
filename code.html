2. Count Characters Using Dictionary

Each character is stored as a key and its occurrences are stored as the value. 


string message = "hello world";

Dictionary<char,int> count =
new Dictionary<char,int>();

foreach(char ch in message)
{
    if(count.ContainsKey(ch))
        count[ch]++;
    else
        count[ch]=1;
}

foreach(var item in count)
{
    Console.WriteLine($"{item.Key}:{item.Value}");
}

Output

Character Count
h1
e1
l3
o2
(space)1
w1
r1
d1
How Dictionary Works
  • ContainsKey() checks whether the character already exists.
  • If yes → Increment count.
  • If no → Add new key with value 1.

3. Count Characters Using LINQ

LINQ provides a concise way to group characters and count their occurrences. 


var result = message
            .GroupBy(c => c)
            .Select(g => new
            {
                Character = g.Key,
                Count = g.Count()
            });

foreach(var item in result)
{
    Console.WriteLine(
        $"{item.Character}:{item.Count}");
}

LINQ Breakdown

Method Purpose
GroupBy() Groups identical characters
Select() Creates anonymous object
Count() Counts grouped items
Advantages of LINQ
  • Readable
  • Less Code
  • Functional Programming Style
  • Easy to maintain
